# Hello Spring Boot

A minimal Spring Boot project that prints **Hello, World!**.

## Tech stack
- Java 17
- Spring Boot 3.5
- Maven
- IntelliJ IDEA

## How to run
1. Open the project in IntelliJ IDEA (`File > Open` and select the `pom.xml`).
2. Wait for Maven to download dependencies.
3. Run `HelloSpringbootApplication.java`.

## Output
- Console: `Hello, World!`
- Browser: open http://localhost:8080/ to see `Hello, World!`
